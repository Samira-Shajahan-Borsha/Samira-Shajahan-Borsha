## Featured Projects

### EventHub
*Multi-tenant event management and booking platform.*

- **Architecture:** Decoupled architecture featuring a Next.js (App Router) frontend and a modular Node.js/Express REST API backed by MongoDB.
- **Challenges:** Orchestrating stateful ticket reservations and asynchronous payment reconciliation within a strict multi-role (User, Host, Admin) environment.
- **Engineering:** Engineered a server-mediated payment pipeline via SSLCommerz, utilizing strict callback verification to guarantee transactional consistency and prevent race conditions during seat reservation. Enforced a secure multi-role environment using HTTP-only JWT cookies and custom RBAC middleware, and built a dynamic API QueryBuilder to power debounced, multi-criteria event discovery.
- **Links:** [Live Demo](https://events-activities-client-five.vercel.app/) · [Frontend Source](https://github.com/Samira-Shajahan-Borsha/events-activities-client) · [Backend Source](https://github.com/Samira-Shajahan-Borsha/events-activities-server)

### RideFlow
*Production-grade ride-booking platform featuring role-aware dashboards and ride lifecycle management.*

- **Architecture:** Decoupled architecture utilizing a React and RTK Query frontend, integrated with a service-oriented Node.js/Express REST API and MongoDB.
- **Challenges:** Synchronizing concurrent ride lifecycles, dynamically managing driver availability, and enforcing strict data isolation across distinct user roles.
- **Engineering:** Engineered a modular backend using a controller-service-model pattern with Zod validation to securely process ride state transitions. Enforced a robust multi-role environment via HTTP-only JWT sessions and custom RBAC middleware, and optimized data aggregation using a centralized API QueryBuilder.
- **Links:** [Live Demo](https://frontend-ride-booking-system.vercel.app/) · [Frontend Source](https://github.com/Samira-Shajahan-Borsha/ride-booking-system-frontend) · [Backend Source](https://github.com/Samira-Shajahan-Borsha/ride-booking-system-server)
